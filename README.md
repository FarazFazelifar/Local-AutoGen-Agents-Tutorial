# Local AutoGen Agents Tutorial

This repository contains examples of running AutoGen agents with locally served language models through Ollama.

I created these examples to explore agent orchestration without relying exclusively on hosted model APIs. The repository includes an introductory notebook, additional agent material, and an example retrieval agent.

## Files

- [Local-AutoGen-Agents-Tutorial-Beginner.ipynb](Local-AutoGen-Agents-Tutorial-Beginner.ipynb) — introductory notebook.
- [rag_agent.py](rag_agent.py) — retrieval-agent example.
- `Agents-Overview-Advanced` — additional material.

These examples reflect the APIs and model configurations used when they were written. If you are using a newer version of AutoGen or Ollama, review its current documentation before running the examples.
